# session-bootstrap（Claude Code版）

目的: セッション開始時の固定コストを最小にし、前回の決定事項を確実に引き継ぐ。
Cowork版（claude.ai同期の `anthropic-skills:session-bootstrap`）と同じ記録形式を使う。Code版の差分は「作業フォルダ＝リポジトリのルート」「記録はcommitしないと消える」の2点。

## 発火条件（これ以外では使わない）
- 使う: 2ファイル以上の調査（grep・構造把握・複数ファイルの読解）／2ファイル以上の生成・変更
- 使わない: 単発の質問、1ファイルだけの修正、対象ファイルが特定済みの小修正 → 復元せずに直接作業し、記録も残さない

## 手順

### 1. 索引だけ読む
- リポジトリ直下の `session-notes.md`（索引、50行以内）を読む。
- 存在しなければ `.claude/skills/session-bootstrap/assets/session-notes.template.md` をコピーして作り、新規タスクとして進む。
- **この時点では、リポジトリ全体、SDK、vendor、build、ログを読まない。**

### 2. 該当タスクのノートだけ読む
- 今回の依頼に対応する `notes/[task].md` を索引から特定し、その**1件だけ**を読む。
- 対応するノートがなければ `notes/[task].md` を新規作成する（テンプレートは `.claude/skills/session-bootstrap/assets/task-note.template.md`）。
- ほかのタスクのノートは読まない。

### 3. 復元内容を5行以内で提示
次の内容を箇条書きで示し、ユーザーの訂正を待たずに続行する（訂正があれば反映する）。
- 前回の決定事項（ADRの見出しだけ）
- 未完タスク
- 接続・参照先（値ではなく参照名）
- 見積補正メモがあれば、その旨

### 4. スコープの確認
- 索引の「使用コネクタ」に載っているものだけを使う。載っていないコネクタが必要なら、使う前にユーザーに1回確認する。
- タスクノートの「対象パス」以外は、model-router の explore サブエージェント（Agent tool, `subagent_type: Explore`）経由で読む。

### 5. 次のスキルへ
- 発火条件を満たしているので、続けて model-router → token-estimate の順に進む。

## 禁止事項
- session-notes.md が50行を超えているのに、そのまま読み進めること（超えていたら先頭に「アーカイブが必要」と表示し、古い項目を `notes/archive/` へ移すよう提案する）
- ノートに秘密値（キー、トークン、パスワード）があった場合にそれを使うこと。使わずに、ユーザーへ削除を促す
