# formula.md — 見積係数（Claude Code版・初期値）

> Cowork版の references/formula.md は claude.ai からの同期に含まれていなかったため、参照していない。
> 下の係数は**すべて仮置き**。実測（estimate.py）で置き換えられる項目は実測を優先し、それ以外は session-close の「見積 vs 実績」で補正する。

| 項目 | 低 | 高 | 出典区分 | 備考 |
|---|---|---|---|---|
| 固定コンテキスト（システム＋CLAUDE.md＋スキル一覧＋MCPツール定義） | 20K | 40K | 仮置き | 接続しているMCPが多いほど高くなる |
| サブエージェント初期化（1体あたり） | 10K | 30K | 仮置き | Cowork版SKILL.mdの「数万トークン（推定）」を幅にした値 |
| 履歴再送（1ターンあたり） | その時点の累積コンテキスト × 1.0 | 同左 | 仕組み上の前提 | キャッシュが効けば課金上は割り引かれるが、コンテキスト長は消費する |
| ツール出力（1回あたり） | 0.5K | 5K | 仮置き | 全文readやログは上振れする |
| 出力（コード1ファイル） | 1K | 5K | 仮置き | |

## 使い方
1. 入力ファイル = estimate.py の合計（実測）
2. 想定ターン数 N、サブエージェント数 M を決める
3. 合計(低) = 固定(低) + 入力 + M×初期化(低) + Σ履歴(低) + ツール(低)×回数 + 出力(低)。高も同様に計算する
4. 補正の実績が3件たまったら、この表を「自己計測」に更新する
