# token-estimate（Claude Code版）

目的: 実行前に消費トークンの概算を出し、「このまま実行／範囲を絞る／Chatで済ませる」をユーザーが選べるようにする。

## 発火条件（これ以外では使わない）
- 使う: 2ファイル以上の調査／2ファイル以上の生成・変更
- 使わない: 単発の質問、1ファイルだけの修正、対象ファイルが特定済みの小修正

## 手順

### 1. 入力スコープの確定
対象のファイル・ディレクトリ・参照資料を列挙する。決まっていなければ最初に1回だけ質問する（AskUserQuestion を使う）。

### 2. 入力トークンの実測（推定ではなく計測）
```
python3 .claude/skills/token-estimate/scripts/estimate.py <path-or-glob> [...]
```
- 除外: build/ dist/ node_modules/ third_party/ vendor/ .git/ *.log *.bag *.bin
- 出力: ファイル別のトークン数、合計、上位10ファイル
- 既定は文字数ベースの概算。`--api` を付け、かつ環境変数 ANTHROPIC_API_KEY があるときだけ count_tokens API で精密に計測する（ファイル内容が外部APIに送られるため、明示したときだけにする）。

### 3. 作業トークンの見積（`.claude/skills/token-estimate/references/formula.md` の係数を使う）
```
合計 ≈ 固定コンテキスト
     + Σ(ターンごとの履歴再送)
     + Σ(サブエージェント初期化 × 体数)
     + Σ(ツール出力)
     + 出力
```
**必ず低／高の幅で出す**。単一の値で断定しない。係数には出典区分（公式／第三者／自己計測／仮置き）を付ける。

### 4. 提示（表1枚、10行以内）
| 項目 | 低 | 高 | 根拠 |
|---|---|---|---|
| 固定コンテキスト | | | CLAUDE.md, MCP, スキル |
| 入力ファイル | | | estimate.py 実測 |
| サブエージェント | | | 体数×初期化 |
| 会話履歴再送 | | | 想定ターン数 |
| 出力 | | | 成果物サイズ |
| **合計** | | | |

続けて3択を示す: (a) このまま実行 (b) スコープを絞る（削減候補を上位ファイルから提案） (c) Chat向きなので移す。
合計（高）が200Kを超えそうなら、(b)か分割を既定で推奨する。

### 5. 実行後の記録
session-close で、`session-notes.md` に「見積（低／高）」と「体感した実績（過大／妥当／過小）」を1行追記し、係数の補正に使う。

## 禁止事項
- 見積をせずに大規模な読み込みを始めること
- 係数の出典区分を示さずに数値を出すこと
